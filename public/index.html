ulogin — 범용 로그인 서비스

로컬 HTML·AI 앱을 위한 인증 서버. 로그인만 서버로 분리해 API 키를 브라우저에서 없앤다.

이 서버는 무엇인가

  1. 로컬 HTML 앱의 JavaScript에 AI API 키를 넣으면, 파일을 여는 누구나 그 키를 그대로 볼 수 있다.
  2. 그래서 로그인만 이 서버로 분리하고, 인증을 통과한 사용자에게만 서비스 시크릿(AI 키·엔드포인트 등)을 내려준다.
  3. 앱은 로그인 후 받은 1회용 코드를 토큰으로 교환하고, 받은 시크릿은 저장하지 않고 메모리에서만 사용한다.

바로 가기

계정

  • 로그인 — 외부 앱에서 SSO 파라미터(service_id, redirect_uri)와 함께 열면 로그인 후 원래 앱으로 돌아간다.
  • 회원가입 — 아이디·이메일·비밀번호와 약관 동의로 가입한다.
  • 비밀번호 찾기 — 가입 이메일로 재설정 링크를 받는다.
  • 이메일 인증 — 인증 메일의 링크로 열리는 화면. 링크 없이 열면 재발송을 요청할 수 있다.

로그인이 필요한 화면

  • 마이페이지 — 내 정보·비밀번호 변경·포인트·로그인 기기·가입 서비스·탈퇴.
  • 관리자 콘솔 — 회원·서비스·시크릿·로그·설정 관리. 관리자 권한이 필요하다.

연동 예제

  • 로컬 AI 앱 데모 — 이 HTML 안에는 API 키가 없고, 로그인 후 서버에서 받아 쓴다.
  • 복귀(callback) 처리 예시 — 코드→토큰 교환과 state 검증 최소 구현.

연동하려면

앱을 쓰기 전에 관리자가 콘솔에서 서비스를 등록하고, 앱의 복귀 주소를 redirect_whitelist에, 앱의 출처를 allowed_origins에 등록해야 한다. 등록되지 않은 복귀 주소로는 어떤 경우에도 이동하지 않는다.

앱 쪽 구현은 assets/ulogin-client.js를 <script src>로 불러 쓰면 된다. 자세한 절차는 저장소의 README.md와 INSTALL.md를 참고한다.
